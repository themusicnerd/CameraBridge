PIVOTCam network

Camera N uses base port + N. With base 19010, camera 1 uses TCP 19011. Each endpoint uses VISCA address 1.

Set the Carbonite PIVOTCam device to CameraBridge's IP and that camera's TCP port. Assign the device to the video input separately.

Each port controls its assigned camera directly. This does not follow the switcher Preset bus. Physical camera acceptance is still required.

Tally input · TSL UMD 3.1 over UDP

Carbonite uses tally 2 for program/red and tally 1 for preview. Input 1 uses address 1. Each camera has a TSL address above. HE130 uses its red lamp; PXW-Z200 external lamps are unavailable through SDK 2.02.00.
