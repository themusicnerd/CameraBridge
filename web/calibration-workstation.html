CameraBridge Video Calibration

Local Workstation

Use this computer for NDI, RTSP, or a Magewell USB capture device. Camera control can stay on the TouchDrive.

1. Select Camera Video

NDI needs the NDI runtime. RTSP and USB capture need FFmpeg. Select the Magewell device that receives the camera SDI or HDMI signal. Start Preview opens only the selected source. Starting a source clears the current calibration batch.

2. Link Camera Encoders (Optional)

The link reads stationary lens encoders and can save results back to CameraBridge. It sends no movement or preset commands. CameraBridge credentials stay in memory. If the camera does not report encoders, use the manual tags below or export an untagged optical solve.

3. Capture a Checkerboard Batch

Use a flat printed checkerboard with a white border. Lock zoom and focus. Keep the video crop and resolution fixed. Wait for the lens and video to settle. Move and tilt the board between captures. Cover the image center and edges. Capture at least 12 different views at one lens setting.

Inner corners are the intersections inside the board, not the number of squares. Print at 100% size and measure a square before use. A new batch clears saved views. Repeat the batch at each zoom and focus setting that you need.

The result contains focal lengths, principal point, and OpenCV distortion coefficients. Reprojection error is a fitting metric, not a guarantee of overlay alignment. Check independent images. Nodal offset and video timing still need separate calibration. The JSON is not an Unreal Lens File. CameraBridge can export the solved field-of-view table for XPression; it does not map OpenCV distortion into XPression lens-correction parameters.
