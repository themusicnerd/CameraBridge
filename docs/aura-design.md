# Aura layout

The panels use a dark Aura-style layout with manufacturer identification images.
They do not contain a Ross logo.
The layout does not change the installed DashBoard theme or libraries.

The header contains navigation and Open CameraBridge.
The left rail contains camera selection, Refresh and STOP.
The main area contains the selected control page.
The footer contains connection or operation status.

Large native fader handles replace small dot sliders.
Control buttons and fields have at least 48 pixels of height.
The panel canvas is 1366 × 800 pixels.
It leaves room for the tree and tabs on the tested 1920 × 1080 TouchDrive desktop.
