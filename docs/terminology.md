# Technical term list

Use one meaning for each term in this documentation.
These are proposed project technical names.
They are not a replacement for the official ASD-STE100 dictionary or editorial approval.

| Term | Meaning |
|---|---|
| API | Application programming interface; the CameraBridge HTTP request interface |
| archive | ZIP or TAR.GZ package that contains release files |
| backend | CameraBridge service that owns camera state and commands |
| bus | Switcher source-selection group, or a shared serial connection; the text identifies which |
| CGI | Common Gateway Interface; the Panasonic HTTP command interface |
| CIDR | Classless Inter-Domain Routing; notation for allowed address ranges |
| configuration | JSON settings that the service reads at startup |
| Custom Control | Named Ross switcher action sequence |
| DashBoard | Ross application that runs the native camera panels |
| emulator | Program that implements the supported Panasonic HTTP test interface |
| epoch | Number that identifies one lab target-selection state |
| fader | Native vertical slider with a large movable handle |
| feedback | Value or status returned by the service or camera |
| firmware | Device software version |
| grid file | Native DashBoard panel file with the .grid extension |
| lab model | Synthetic Marshall state; not a serial camera emulator |
| loopback | Network address that refers to the same computer |
| OGLML | Native DashBoard panel description format |
| ogScript | DashBoard scripting interface |
| paint | Camera image settings, such as white balance and detail |
| parameter | One named camera setting |
| Preset | Ross switcher preview-selection bus when capitalized |
| Program | Ross switcher output-selection bus when capitalized |
| readback | Independent query result after a setting change |
| relay | Restricted program that forwards Carbonite traffic to the lab listener |
| RS485 | Electrical serial connection used by applicable Marshall cameras |
| session token | Temporary login value that permits authenticated requests |
| shot | Stored camera framing or the corresponding recall/store command |
| simulator | General label for an emulator or synthetic lab model |
| TD1C | TouchDrive development panel model |
| VISCA | Camera control message protocol |
| camera number | Persistent numbered camera assignment; separate from the video input |
| tray | Desktop area that contains the CameraBridge control icon |
| control panel | Native desktop window for service and port settings |
| VNC | Remote desktop protocol used to inspect the TouchDrive |
| watchdog | Timer that attempts to stop movement after valid input stops |

Product names, file names, code identifiers and exact interface labels retain their original spelling.
Use shot for camera memories and snapshot for saved paint values.
Do not use these two terms with the same meaning.
